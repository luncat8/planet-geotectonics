# Дизайн системы: эмерджентная тектоника и металлогения на статической икосферной сетке

**Версия:** 1.0 (design freeze для составления плана разработки)
**Статус предыдущих решений:** перенесено из обсуждений; противоречия сняты, финальные решения ниже.

---

## 0. Пересмотр по флюидам (фиксируем решение)

Цитируемый аргумент верен для масштаба от десятков метров до ~1 км. При ячейках **10–50 км** путь флюида — субсеточная величина: источник, сток и осаждение почти всегда попадают в одну ячейку или соседнюю. Следствия для дизайна:

- **Растворённая фаза (m\*) не хранится и не переносится.** Поле «подвижный металл» исключено из состояния.
- Не моделируем *куда* течёт флюид — моделируем *генерацию* (перегрев, дегидратация) и *разрядку* (кипение, выхлоп на дно, смешение). Осаждение — локальный триггер + ядро рассеяния на 1–2 клетки (один проход блура).
- **Планетарный перенос металла выполняет не флюид, а тектоника:** субдукция поглощает рудоносную кору → дуга возвращает обогащённый магматический флюид. Это реалистично (так и работает) и бесплатно — вся инфраструктура уже есть.
- Единственный поверхностный перенос — **россыпной**: доля золота адвектирует вместе с потоком осадков.

Это упрощает систему на один ping-pong-буфер и один Дарси-проход. Возврат к транспортной фазе имеет смысл только при клетках < 5 км — фиксируем как не-цель.

## 1. Масштабы и бюджет

| Уровень | Клеток | Ребро/ячейка | dt (CFL 0.5) | Назначение |
|---|---|---|---|---|
| L5 | 10 242 | ~220 км | 1–2 млн лет | CPU-референс, отладка |
| L6 | 41k | 110 км | 0.5–1 | разработка механик |
| L7 | 164k | 55 км | 0.25–0.5 | интерактив в игре |
| **L8** | **655k** | **28 км** | **0.15–0.25** | **целевой рендер** |
| L9 | 2.6M | 14 км | 0.08–0.15 | stretch-цель |

- Скорости плит 1–10 см/год = 10–100 км/млн лет. Цикл Вильсона ~500 млн лет ≈ **2500–3500 шагов на L8**.
- Память на L8: состояние ~65 МБ, таблицы соседей ~60–130 МБ (см. §8), AUX ~40 МБ. Итого < 300 МБ.
- Производственная цель: **полный шаг ≤ 15 мс на L8** (10–12 compute-проходов по ~0.5–1.5 мс) → ≥ 60 шагов/с интерактивно, ≥ 300 шагов/с в фоновом fast-forward. CPU-референс L5 — ≥ 30 шагов/с в JS.

## 2. Данные

Переиспользуется существующий `Grid.build()`: `cellA` (центр+площадь), `nbrA/nbrB` (соседи, метрики рёбер, ротация базисов), `lookup`. `cellC` становится **производимым** полем (проход TOPO), статическая батиметрия остаётся fallback-режимом.

### Состояние (сохраняется, ping-pong, RGBA32F)

| Буфер | x | y | z | w |
|---|---|---|---|---|
| **CRUST** | `h` толщина коры, м | `m` мафитовая доля магматической части [0..1] | `s` осадки, м | `W` связанная/гидратированная вода (отн. ед.) |
| **DYN** | `u1` | `u2` (базис e1/e2) | `zDyn` динамич. топография, м | `age` возраст океанич. литосферы, млн лет |
| **GEO** | `oB` руды base-класса (Cu-Zn-Ni) | `oL` litho-класс (U-Sn-W) | `oP` prec-класс (Au) | `k` проницаемость/повреждённость [0..1] |

Фельзит **не хранится**: `fFels = 1 − m − sNorm` (sNorm — нормированная объёмная доля осадков). Континентальность — производный индекс:
```
ci = smoothstep(h; 12e3 → 20e3) · (1 − smoothstep(m; 0.45 → 0.7))
```
Океаническая кора: h≈7 км, m≈0.9, ci≈0. Континентальная: h≈35–70 км, m≈0.2–0.4, ci≈1. Рифт плавно ведёт ci→0, коллизия ci→1. Граница океан/суша — из ci + z (§5.6).

### Scratch (пересчитывается каждый шаг, не сохраняется)

| Буфер | Содержимое |
|---|---|
| AUX-A | `T` (темп. прокси), `Pf` (потенциал разрядки флюида), `H` (магматический источник тепла), `bt` (тип границы со сглаживанием) |
| AUX-B | `div`, `S` (2-й инвариант), `mM1, mM2` (скорость мантии в базисе) |
| AUX-C0/C1 | temporaries: MacCormack-полушаги, блур руды, флексура |

Плюс CPU-скаляры: `t`, `Tm` (температура мантии), счётчики резервуаров, `seed`.

**Правило детерминизма:** каждый проход пишет только в свою ячейку (симметрия рёбер — через коэффициент 0.5 с обеих сторон). Тогда порядок диспетчей не влияет на результат → воспроизводимость и реплеи без барьеров. Атомики — только в диагностике (fixed-point u32).

## 3. Конвенции

- **Две скорости на ребре** (критично): транспорт — `unFace = ½(unI + unJ)`; деформация и классификация — `relN`, `relT` из разности скоростей с ротацией соседа `(rotA, rotB)`. Классификация границ — **только по relN/relT** (при симметричном лобовом столкновении `unFace`≈0), балансы массы — по `unFace` + явные стоки.
- Времена — в млн лет, длины — в метрах, всё через `R`.
- Шум (гармоники мантии, провинциальная фертильность) — детерминированная функция `(seed, t)`.

## 4. Пайплайн одного шага (dt)

| # | Проход | Вход → Выход | Содержание |
|---|---|---|---|
| P1 | OPS | DYN → AUX-B, AUX-A.bt | div, curl, S; классификация рёбер (гистерезис, мёртвая зона) |
| P2 | FORCE | DYN, AUX-B, скаляры → DYN' | ridge push, slab pull, коллизионное сопротивление, drag мантии; ν_eff = ν0/(1+(S/Sy)²) |
| P3 | PROJ | DYN' → DYN | жёсткая проекция на ω-кластеры (см. §5.1), вес λ_eff гасится при S→Sy |
| P4 | TECT | DYN, CRUST, GEO → CRUST', DYN', счётчики | спрединг, рифтинг, субдукция, коллизия, инициация субдукции |
| P5 | EROS | z, CRUST → CRUST' | эрозия ∝ max(0, z−zEq), снос осадков вниз по склону, россыпная доля oP |
| P6 | GEOCHEM | CRUST, GEO, AUX-A/B → GEO', AUX-A | T, Pf, обновление k; выщелачивание → осаждение (§5.5); дуговая инжекция |
| P7 | ADV | CRUST, DYN.age, GEO(oP-россыпь) → *' | консервативный upwind потоками unFace; MacCormack/антидиффузия m — опционально |
| P8 | TOPO | CRUST, DYN, GEO →AuxC | изостазия, z, wet/dry, батиметрия из age; (периодически coastDist BFS) |
| P9 | DIAG | всё → маленький буфер | редукции: массы, Σore по классам, max|u|, CFL, число плит, NaN |

Составление плана разработки — прямо из этой таблицы: каждый Pn = отдельный compute-шейдер с известными входами/выходами.

## 5. Модули

### 5.1 Плитная динамика

**Силы** (на ячейку, нормировка на площадь; рёберные вклады — симметрично, по 0.5 с каждой стороны):

```
F_ridge = −kRp · ∇z                                    // гравитационное растекание со склона хребта
F_slab  = Σ_edges kSp · min(1,√(age/70)) · |relN⁻| · n̂   // только конвергентные, только океан, age>10
F_coll  = −Σ_edges kCo · |relN⁻| · n̂                    // только ci_i>0.5 && ci_j>0.5
F_drag  = cD(Tm) · (u_mantle − u)
```

u_mantle = Σ aₖ ∇⊥Yₖ(dirs, freqs, phs) — существующая гармоническая машина; амплитуда ∝ Tm^2.5.

**Жёсткость без хранения label.** Канал метки исключён (лагранжева сущность на эйлеровой сетке — источник артефактов). Вместо него, раз в N=16–32 шага:
1. На GPU — k итераций сглаживания u с гейтом |Δu|<ε (локализация кластеров без union-find).
2. Readback прореженной выборки u (каждая 8–16-я клетка, десятки КБ) → на CPU: кластеры по остатку скорости, МНК-фит ω на кластер (замкнутая 3×3-система, плит ≤ 64), upload маленького uniform-массива.
3. Проход PROJ: каждая клетка находит лучший кластер по |u − ωₖ×x| и релаксирует `u += λ0·(1−min(1,S/Sy))·(ωₖ×x − u)`.

Сплиты и мерджи бесплатны: кластеры пересчитываются сами. Диффузия скорости остаётся только внутри зон деформации через ν_eff.

**Застывание планеты.** Глобальный скаляр:
```
dTm/dt = −a·Tm⁴ + b·Hrad(t)     (Hrad убывает)
```
Tm управляет: амплитудой мантийного потока (∝Tm^2.5), вязкостью drag (∝exp(Ea/Tm)), дуговым магматизмом (∝Tm). Горячая ранняя Земля → быстрые мелкие плиты; холодная поздняя → медленные крупные → почти静止ная литосфера. Никаких жёстких переключателей — u_rms просто сползает к нулю.

### 5.2 Тектонические процессы (P4)

| Процесс | Условие (по relN, ci, age) | Действие |
|---|---|---|
| Спрединг | relN>+ε, ci<0.5 | age=0, h=7 км, m=0.9, W+=, zDyn += хребет |
| Рифтинг | relN>+ε, ci>0.5 | h−=, m↑ (мафические интрузии), ci↓; при h<15 км — рождение океана, age=0 |
| Субдукция | relN<−ε, ci<0.5 на одной стороне | q ∝ |relN|: h−=q на поднырывающей, W→Pf (дегидратация), zDyn−= (желоб), heat+= на нависающей, счётчик в резервуар |
| Коллизия | relN<−ε, ci обе >0.5 | h+= до 80 км, zDyn+= (ороген), сопротивление kCo, импульс честно перекачивается (симметрия) |
| Инициация субдукции | океан-океан, relN<−ε, age одна ≥1.5× другой | тонет более старая; океан-континент → океан снизу |

Полярность дуги: нависающая сторона = та, чья скорость направлена от границы; тепло и инжекция — на неё (смещение на 1 клетку от желоба).

### 5.3 Эрозия и осадки (P5)

`s` переносится потоком вниз по склону (flux ∝ −∇z·kD, upwind), осаждение там, где уклон мал. Доля `β≈0.25` от oP адвектирует с этим же потоком → россыпи ниже золотоносных поясов. Это единственный поверхностный перенос руды.

### 5.4 Тепло и флюид (P6, первая половина)

```
T  = k1·H + k2·h·fFels + k3·f(age)          // квазистатический прокси
Pf = η·(дегазация интрузий H + дегидратация W) + глубинная составляющая
k' = k + a·S − b·k                          // damage от деформации, медленное заживление
```
Направление течения не вычисляется — только величины источников и готовность к разрядке (решение §0).

### 5.5 Металлогения

Фертильность — свойство литологии × провинциальный шум (гармоники, множитель 0.5–2, детерминированный по seed). Выщелачивание пропорционально Pf×T. Осаждение — триггерное, всё из существующих полей:

| Класс | Источник | Триггер осаждения | Результат-география |
|---|---|---|---|
| **oB** (Cu-Zn-Ni) | мафит (m) | выхлоп горячего флюида: bt=RIDGE (VMS); над дугой при высоком H (порфиры) | хребты + дуги |
| **oL** (U-Sn-W) | фельзит (fFels) | восстановитель: s>0.3 при низких T | внутрикратонные бассейны на старой коре |
| **oP** (Au) | мафит + изменённые породы (W высокий) | кипение (сброс Pf), сдвиговые зоны (k высокий, пояса коллизии); далее β-доля — в осадочный поток | коллизионные пояса + россыпи |
| Fe | производный прокси: экспонированный m + интрузии | — | без отдельного состояния (BIF — backlog) |

После триггеров — **один блур-проход (1–2 клетки)** как гало рассеяния. Замыкание цикла: субдукция списывает рудоносную кору в счётчик → дуга возвращает часть с **коэффициентом обогащения ×5–10** (фракционирование) → порфировые районы возникают там, где перерабатывается старая кора. Насыщение: темп осаждения ∝ (1 − ore/oreMax).

### 5.6 Топография, изостазия, уровень моря (P8)

```
zOcean = −(2600 + 350·√age)                // Парсонс–Слэтер
zCont  = A·(h − 30e3) + B·s                // Эйри, калибровка: 35 км → ~+400 м
z = mix(zCont, zOcean, ci) + zDyn
```
zDyn релаксирует лапласианом (флексурные прогибы вокруг нагрузок — бассейны по краям орогенов). Уровень моря v1 — константа; эвстатика от объёма хребтов — backlog (§10).

## 6. Эмерджентные сценарии → механизмы (требования заказчика)

| Требование | Механизм | Что наблюдаем |
|---|---|---|
| Появление плит | вязко-пластичная локализация + мантийный поток | границы = полосы высокого S, интерьеры жёсткие |
| Появление континентов | дуги нарастают h и фельзит (дифференциация m↓), ядра аккрецируют коллизиями | батолиты → кратоны без скриптинга |
| Силы, двигающие континенты | slab pull (∝√age) + ridge push; континент — пассажир | скорости 1–10 см/год |
| Горы и впадины при столкновении | утолщение до 80 км + zDyn + флексура + осадочная загрузка | орогены + передовые прогибы |
| Раскол плиты | рифтинг-правило + пересчёт кластеров | полоса растяжения режет плиту, кластеры расходятся |
| Застывание при охлаждении | Tm(t) → затухание потока, роста drag, дуг | эра «малоподвижной крышки» |
| Концентрации → месторождения | §5.5 | таблица географии выше |

**Начальное состояние («горячая Земля»):** равномерная мафическая крышка h=7±1 км, m=0.85±0.1, s=0, age~U(0,20), Tm=1.0 (горячо), u от мантийных гармоник. Континентов нет — весь сиаль нарабатывается дугами.

## 7. Детерминизм и управление временем

- Fixed timestep с CFL-ограничением, субшаги в бюджет кадра (аккумулятор).
- Fast-forward — асинхронно, без рендера, ≥300 шагов/с (L8).
- Сохранение = CRUST+DYN+GEO (~32 МБ на L8, сжимаемо) + скаляры {t, Tm, seed, счётчики, level}. AUX не сохраняется.
- Кольцо чекпоинтов (каждые ~20 млн лет) для скраббинга таймлайна UI.
- Весь шум — `f(seed, t)`; реплеи побитово совпадают.

## 8. WebGPU-мэппинг

- **Хранилище:** storage-буферы `array<vec4<f32>>`; ping-pong через смену bind group. Текстуры не обязательны.
- **Соседи:** nbrA как `array<vec4<u32>>` (idx + len/dist в f16-упаковке), nbrB как f32×4 — ~96 Б/клетку (63 МБ на L8). Опция экономии: хранить только idx (24 Б/клетку), метрики пересчитывать из позиций на лету.
- **Диспетчи:** 9–12 проходов/шаг (таблица §4), workgroup 64/256, по одному на проход.
- **Атомики:** запрещены в путях состояния (правило §2 — порядок не влияет); разрешены в DIAG в fixed-point u32; моменты кластеров — CPU-side из readback.
- **Readback:** DIAG-буфер (сотни байт) каждый шаг или через K; выборка для кластеризации — каждые N шагов.
- **Рендер-хук:** TOPO пишет z/wet/ore-прокси в буфер, готовый к рейкасту сферы через существующий `lookup`.

## 9. Диагностика и критерии приёмки

Инварианты: Σ(A·h), Σ(A·ci·h) (сиаль), Σ(A·s), Σ(A·ore) по классам; дрейф < 1%/100 млн лет, кроме явно учтённых стоков (субдукция → счётчик → возврат дугами); max|u|, CFL, число плит, NaN-сторож.

**Acceptance-пробы (изначение «принципиально работает»):**

1. Из горячего стартa за ~500 млн лет без скриптинга возникают кратоны; скорости 1–10 см/год.
2. Полный цикл Вильсона между двумя кратонами (раскол → океан → закрытие → коллизия) за ≤ 300–600 млн лет симуляции.
3. S в интерьере плиты ≥ 10× ниже, чем на границах; разброс скоростей в кластере < 10%.
4. При Tm→0: u_rms → 0, магматизм гаснет, новые рифты не возникают.
5. География руд: >60% oB — в клетках, смежных с конвергентными границами (нависающая сторона); oP — в поясах коллизии/сдвига + россыпной хвост ниже по склону; oL — в бассейнах на старой фельзической коре. Проверяется скриптом-пробником по bt/h/age.
6. Стабильность: 2 млрд лет без NaN, полосчатых артефактов сетки, фликера классификации (<5% граничных клеток меняют тип за шаг).

## 10. Риски и отложенное (не блокирует план)

| Пункт | Статус |
|---|---|
| Диффузия континентов при upwind | MacCormack/шарпенинг как флаг; дрейф-сторож обязателен |
| Флексура одним лапласианом | приёмлемо для игры; настоящая упругая пластина — backlog |
| Истощение фертильности | v1 — бесконечный фон; затем вычитание из поля-источника |
| Эвстазия, красокс/BIF, климат→эрозия, гидратация как полный цикл воды | каналы запасены (AUX-C, spare), не входят в v1 |
| L9 (2.6M) | тот же код, проверить бюджет соседей |

---

**Итого для следующего этапа:** план разработки строится 1:1 по таблице §4 (P1–P9 = задачи), с CPU-референсом на L5 и параллельным GPU-портом тех же проходов; критерии готовности каждого прохода — из §9. Все проектные развилки, где возможна переработка (флюиды, label, типы плит), закрыты решениями §0 и §5.1 — переделывать не придётся.
