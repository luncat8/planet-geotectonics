## What the two sides built

Both implemented the same increment after 0.6.0, with incompatible core data models:

| | this branch (`d909476`) | alternate (`a35019a`) |
|---|---|---|
| version | 0.6.1 | 0.6.2 |
| catalogue | 3 families, **continuous ellipsoids** (lognormal grades, strike/dip, real drill-ray intersection) | **13-row class table**, 7 kinds, quantized percentile ladders, published `source` per row |
| identity | cube-sphere tile (fixed to the *planet*) | plate **body-frame** anchor (fixed to the *plate*) |
| instruments | 6, incl. **seismic** | 7, no seismic |
| economics | **USD price/opex/capex model** | geological grade/size/depth screen only |
| extra | `0.7-proposed.md`, `SOURCES.md` | `js/core.js` core logs, regional campaign + viable map, calibration experiment |
| tests | 35 pass | 36 pass |

## The merge

I took the alternate as trunk (more kinds, the plate-frame anchor is the physically correct one, its numbers were revised where measurement contradicted them, and 0.6.2 was already built on it) via `git merge --allow-unrelated-histories -X theirs` → a real two-parent merge `d965205` (`parents: d909476 a35019a`), then hand-merged on top in `b51e010`.

**Kept from this branch** (things the alternate never had): the **monetary scenario**, **reflection seismic**, `0.7-proposed.md` (the alternate's own `AGENTS.md` cited it but the file was missing there), and `SOURCES.md` (rewritten for the shipped class table).

**Deleted** 4 files that survived the merge but couldn't run — verified, not assumed: `node tests/prospector.js` → `TypeError: Deposits.snapshot is not a function`, and all 10 old API symbols returned 0 matches in the merged `deposits.js`.

## Two bugs the port exposed, both found by measuring

1. **A flat $44/t opex made every placer and porphyry uneconomic** regardless of grade — a gold dredge moves a tonne for a few dollars, a stope costs 10× that. Cost is now method-based across 7 mining methods.
2. **`contained` isn't uniformly tonnes** — a `ct/t` grade lands in *carats*, so pricing diamond per tonne gave a kimberlite a median net of **13,125 G$**. Units are now declared and a mismatch is refused. Same deposit: **0.77 G$**. `tests/instruments.js` asserts the invariant across all 13 rows.
