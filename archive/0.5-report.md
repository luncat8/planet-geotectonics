## Continued development — 0.5.5 (plan §13): the heightmap lattice + analytic normals

- **`Render3D.gridMesh(cols, rows)`** — `(cols+1)×rows` vertices, duplicated seam column, degenerate pole quads (`2·cols`, discarded not special-cased), CCW-outward winding, unit positions. It's 10–17× cheaper to build than an icosphere of the same class: **1024×512 = 35 ms / 18.0 MiB** vs k8 = 376 ms / 22.5 MiB.
- **Analytic normals** — a WGSL source variant: central differences of the height texture one texel either way, scaled to true arc length, as a height-field gradient in the local east/north/up frame (with a `cos(lat)` floor so pole vertices stay finite). The sea shell and rim keep their radial normal in both modes, so the water look can't shift.
- **Live switches** — Mesh / 3D detail / Normals selects. `setMesh` swaps only the vertex buffers, `setNormals` only the three pipelines: no world rebuild, and no session teardown (0.5.0's detail change released the session and, on the CPU engine, requested a fresh adapter+device).
- **URL** `?mesh=grid&norm=analytic&k3d=1024x512` (bare `?k3d=7` still works), probe `3D on · icosphere k7 · …` / `heightmap 1024x512`, header `· mesh grid · 512x256 · norm analytic`.
- **Tests** — `render3d` (both meshes through one geometry checker, the detail vocabulary, live `setMesh`/`setNormals` identity, staging release), `wgsl-struct` (61 sources; each normal variant checked for the varying, call sites and the presence/absence of the differentiator), `gui` (selects ship the module's vocabulary, URL pre-fill, mode-aware detail list, live swaps, honest inspector), `adj` now gets the `Render3D` global the page ships. The smoke page's §3D gained a lattice + analytic session and a live swap back (the only place those shaders actually run).
