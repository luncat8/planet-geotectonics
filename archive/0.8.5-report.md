## 3. A3 — selected-cut delivery, paused clock, display-side snap, and quad-strip overlay

### 3.1 Selected-cut handoff (`SectionHost.loadPack`) and paused clock (`SectionHost.applyClock`)

- `#host-load-cut` ("Load selected cut") in `#host-panel` enables when both a validated
  globe section export (`section.path && section.result && !section.exporting && !reconLive`)
  and a running hosted section (`SectionHost.state === 'running'`) exist.
- Clicking `#host-load-cut` captures the current cut (`captureSection`, including the GPU
  drain when WebGPU is active), verifies `SlicePack.validate(result.pack) === ''`, and passes
  the exact pack object (`result.pack`, identical `checksum` to Copy/Save) to
  `SectionHost.loadPack(result.pack, { pathChecksum: result.pathChecksum, tMyr: state.t, paused: !playing })`.
- `SectionHost.loadPack` calls `COLSECTION.loadPack(pack, 'selected-cut')` in `try/catch`:
  - On refusal (e.g. checksum mismatch or an open window wider than the 40,030 km wrap):
    `COLSECTION.loadPack` throws before mutating `COLSECTION.pack`, `COLSECTION.world` or
    `COLS`, so the previously mounted section stays running and intact, and the refusal is
    surfaced on `#host-status` and `#section-status`.
  - On success: `SectionHost.syncClock` delivers `{ pathChecksum, tMyr, paused: true }` to
    `COLSECTION.applyClock(..., 'manual')`. Because `COLSECTION.applyClock` sets
    `COLSECTION.syncLive = true` even on a paused manual clock, `SectionHost.statusText()`
    computes `live = !!(COLSECTION.syncLive && !COLSECTION.syncPaused)` so a paused manual
    handoff still leads with `standalone` (`standalone · selected cut <path8>/<pack8> via
    loadPack · section mode on · globe clock paused`).

### 3.2 Display-side snap modifier (`Slice.snapSecond` and `#section-snap`)

- `Slice.snapSecond(state, aWorld, bWorld, mode)` (`js/slice.js`) supports `Slice.SNAP_MODES`
  (`['none', 'boundary', 'motion']`):
  - `'none'`: returns a copy of `bWorld` bit-for-bit.
  - `'boundary'`: finds the nearest active boundary edge (`state.edgeType[e] > 0`), projects
    its across-boundary normal `pos[j] - pos[c]` (perpendicular to the Voronoi boundary
    segment) into the tangent plane at `aWorld`, orients it toward `bWorld`, and places the
    second point at the same angular separation `theta` from `aWorld`.
  - `'motion'`: projects local plate velocity `state.vel` at the origin cell into the tangent
    plane at `aWorld`, orients it toward `bWorld`, and places the second point at the same
    angular separation `theta` from `aWorld`.
- `#section-snap` (`index.html`, `js/ui.js`) and `Shift`/`Alt` click modifiers store the
  unsnapped second click in `section.rawB` alongside `section.b`. Switching `#section-snap`
  between `none`, `boundary` and `motion` re-runs `Slice.snapSecond(state, section.a, section.rawB, mode)`
  before `Slice.circleThrough`; returning to `none` restores `section.rawB` bit-for-bit in
  one click without touching `section.a`, any kernel, or `state`.

### 3.3 Cut-plane quad-strip overlay (`SectionHost.overlayFor` and `paintSliceOverlay`)

- `SectionHost.overlayFor(currentResult, contextStaleReason)` calls `COLSECTION.overlay()`
  and enforces the identity-drop rule (`0.8.5-answer.md` §3.2):
  - Returns `null` immediately when `currentResult` is absent, when `contextStaleReason` is
    non-empty (world time or sea assumptions changed after the export), when `ovl.packChecksum`
    differs from `currentResult.checksum`, or when `ovl.pathChecksum` does not match the
    current cut's path identity.
- When `SectionHost.overlayFor` returns a matching overlay, `paintSliceOverlay()` (`js/ui.js`)
  draws a 6 px screen-space quad strip along `section.path` for each segment `[s0, s1]` using
  `SlicePack.directionAt`, `MapView.project`, preallocated scratch typed arrays
  (`slicePointer`, `sliceProjected`, `sliceProjected2` — zero per-frame allocations), and
  `ovl.palette.lith[seg.lith]`. Stepping world time, changing sea level/volume, starting a
  new cut, switching bundles, or closing the host panel immediately drops the quad strip.

## 4. A4 — automated observation return (`exportActive` → `CoreLog.importText` → `note()`)

- `SectionHost.pullObservation(table, currentArtifact, options)` and `#host-pull-log` ("File
  active observation") in `#host-panel` implement the A4 return loop (`0.8.5-answer.md`
  §3.3/§3.5):
  - Calls `COLCORELOG.exportActive()`. When `null` is returned, reports `'No observation is
    due from the active section.'` and never calls `COLCORELOG.note()`.
  - Passes `due.text` through `CoreLog.importText(table, due.text, currentArtifact)`:
    - `current` (`committed: true`): files the immutable entry in `coreLogTable` and calls
      `COLCORELOG.note()` once.
    - `confirmation-required` (same path + `arcKm`, different `packChecksum`): prompts the
      user via `confirm(...)`. If confirmed, re-imports with `{ confirmStale: true }`, files
      as `stale`, and calls `COLCORELOG.note()` once; if declined, leaves `coreLogTable`
      untouched and does NOT call `COLCORELOG.note()` so the observation stays due on the
      section side.
    - `foreign` (`pathChecksum` or `arcKm` mismatch) or corrupt wire text: refuses without
      mutating `coreLogTable` and never calls `COLCORELOG.note()`.
- **Cross-repo path-checksum compatibility found and resolved during real-tree rehearsal:**
  the slice's `COLCOUPLING.pathChecksum(pack)` (used by `COLSECTION.observe()`,
  `COLCORELOG.exportActive()`, `COLSECTION.overlay()` and `COLSECTION.applyClock()`) hashes
  `JSON.stringify(pathBody(pack))` via `COLDEPOSITCORE.fnvText`, whereas
  `SlicePack.pathChecksum(pack.path)` hashes `'pgt-slice-path-v2\n' + JSON.stringify(pathBody(pack))`.
  `CoreLog.artifact(pack)` (`js/core-log.js`) now records both `pathChecksum` (`SlicePack`)
  and `couplingPathChecksum` (`COLCOUPLING`) for the active cut, and `SectionHost` bridges
  both on `syncClock` and `overlayFor`, so both shared port fixtures and live/standalone
  slice exports validate cleanly while any foreign path is still refused.
- Manual paste/file core-log controls (`#core-log-file`, `#core-log-text`, `#core-log-import`)
  remain unchanged as the fallback rung.
