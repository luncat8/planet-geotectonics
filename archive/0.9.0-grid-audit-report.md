# 0.9.0 grid compatibility audit

The first audit-only portion of the climate seam plan is implemented in
`experiments/grid-compat.js`. It loads the climate classic script in an isolated Node VM;
no climate source is copied into this repository and no simulation behaviour changes.
The VM loads trusted checkout code, not untrusted user uploads.

## Reproduction

```sh
node experiments/grid-compat.js ../planet-climate > experiments/logs/grid-compat.txt
```

The checkout argument is required; optional minimum/maximum levels default to 3 and 7.
Output is JSON on stdout; diagnostics go to stderr and any failed comparison exits 1.
The script does not write files itself. The record includes the climate revision, grid-file
SHA-256 and whether that file has local changes. External checkout tests stay separate
from the short profile, which requires neither network nor another repository.

V/W/H and lookup dimensions match at all five levels. Distance is the angle between
centre vectors times Earth radius; `atan2(|cross|, dot)` avoids interpreting float32
radial rounding as a false kilometre-scale displacement. The declared angle tolerance
is 1e-6 rad (~6.37 m); ring slots and lookup IDs must match exactly.

This establishes index correspondence for these grid implementations and inputs, not
permanent cross-repository index compatibility or equivalence of surface/physics fields.
Direction-based mapping remains the integration default until a host pins and checks both
versions. No area conservation, climate dynamics, browser or hardware-performance claim
follows from this audit.

## Boundaries

Only the grid audit portion of 0.9.0 is complete. No unused temperature, precipitation or
ice keys were added to Params: future consumer names/units must be chosen with the actual
forcing implementation. No climate host, shared port module, clock or kernel change ships.
The 0.8 counterpart/manual round-trip and owner-GPU gates remain unchanged.

`tests/grid-compat.js` uses a local synthetic climate-layout fixture and exercises loading,
float32/radial error, direction changes, ring and lookup drift, malformed input and CLI
refusals. It runs in the short profile. The external L3–L7 comparison is a separate command.
