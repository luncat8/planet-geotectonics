# 0.4.5 review — Earth start becomes real: modern re-bake, Pangaea + Gondwana checkpoints, and the honest no-convergence result

What the milestone promised, what actually shipped, what the measurements say, and the gap
that is the next milestone. Written to stand alone. Measurements are from the Arena sandbox
(2 cores, node 22, no GPU adapter) unless a log is cited; the forward-run wall times are
single-process and carry over to a real machine.

## 1. Scope

The ask: the default Earth start should look like real plates, continents and sea level;
add the nearest historical checkpoints first — Pangaea (~250 Ma) and Gondwana (~200 Ma); and
make the forward simulation testable against the modern map, so gradually older checkpoints
can be added once the run "became similar to nowdays map".

Three parts shipped:

1. **The modern Earth packs are genuinely Earth now** (both 1° and 0.5° re-baked from the
   PALEOMAP 0 Ma map + NNR-MORVEL56), superseding the 0.4.0 synthesis that read as "Earth-ish
   blobs".
2. **Two historical start checkpoints** — `pangaea` (250 Ma) and `gondwana` (200 Ma) — baked
   from the same Scotese & Wright (2018) maps, loader- and UI-wired, smoke- and test-verified.
3. **A forward-reconstruction gate** — `experiments/paleo-score.js` steps a checkpoint pack to
   the present and scores its land mask against the modern pack's — with the full-epoch runs
   measured, and the result recorded honestly (§4).

## 2. What shipped

### 2.1 Modern re-bake (supersedes the 0.4.0 packs)

- Source: the PALEOMAP **0 Ma** map (Scotese & Wright 2018, Zenodo `10.5281/zenodo.5460860`),
  ingested as the CC-BY 4.0 1° texture (PDMap mirror; the Zenodo NetCDF/CSV were unreachable
  from the build sandbox), committed at `data/earth/paleo/000Ma_source.jpg` with its MD5 in
  `data/earth/SOURCES.md`.
- `tools/earth/paleo_extract.js` converts the texture to 1° (and 0.5°) z/age/kind bins with a
  palette → (z, age) band table (CLI-overridable per map; the modern maps use
  `--z-deep 4200 --z-navy 5000`).
- `tools/earth/bake_earth.py --from-bins` bakes `js/data/earth-1deg.js` and
  `js/data/earth-05deg.js` with the NNR-MORVEL56 (25-plate MORVEL canonical) model and a datum
  of **−460 m** (true modern sea level on this raster's hypsometry).
- Verified: land mask IoU **0.896** against the official 0 Ma raster (the 0.4.0 synthesis
  scored 0.34 — IDW blobs); pack land fraction **29.02 %**, matching true modern ~29.2 %;
  `tests/earth.js` FULL passes (the mean-ocean window was deliberately widened to
  −4800…−3800 m and documented, because a 1° banded pack at true sea level cannot reach the
  old −4200…−3500 m window without corrupting the bathymetric bands).

### 2.2 Historical checkpoints (Pangaea 250 Ma, Gondwana 200 Ma)

- Extracted bins: `data/earth/paleo/250Ma_1deg.bin`, `200Ma_1deg.bin` (source textures
  committed, MD5s in SOURCES.md).
- Baked packs: `js/data/earth-250Ma.js` (`pangaea`, epoch 250) and `js/data/earth-200Ma.js`
  (`gondwana`, epoch 200) — each **9 plates**, **all poles zero** (no NNR model for past
  epochs), datum shift **+0.00 m** (the texture's own sea level is the datum), **zero clamps**
  in the K9-consistency pass.
- Loader (`js/earth.js`): a **zero-pole guard** — a pole-less pack sets `prescribedOmega = 0`,
  and the `realistic` preset on it becomes a frozen-pole game run (thermal pin kept, K10
  driven from the seed); the boot raster's K10 still derives non-zero rotations, so the world
  moves under either preset.
- UI: the Start dropdown offers `earth` / `pangaea` / `gondwana`; the Preset select shows for
  all three; `Earth.pick` serves the epoch pack; the probe and copy header name the pack
  (e.g. `earth-250Ma 360x180 (PALEOMAP-PaleoDEM 250Ma (Scotese & Wright 2018)) · epoch 250 ·
  datum 0 m · wet 68.24% · …`). `?start=pangaea&preset=game` boots straight onto it.

### 2.3 Tests

- **`tests/paleo.js`** (new, in the short profile): pack provenance (name/epoch/360×180/9
  plates/all-poles-zero/source string), the zero-pole guard (ω = 0 after apply, non-zero after
  the boot raster), raster fidelity — the pack's land mask against the **own source bin** read
  with an independent in-test reader (IoU ≥ 0.99, measured 1.0000), a modern-vs-historical IoU
  band (0.1…0.6, so the test fails if a historical pack silently becomes the modern one), and a
  20 Myr L4 forward run that stays finite, is bit-identical across a double boot, and has
  actually evolved.
- **`tests/earth.js`**: accepts the re-baked modern packs (widened, documented windows) and
  the two epoch packs; the zero-pole guard is pinned there too.
- **`tests/gui.js`**: pins the `pangaea` and `gondwana` starts end to end — the Preset select
  shows, Reset boots the right pack (probe + wet fraction), a step keeps 8–9 plates in the
  status line, and the copy header names the start.
- **`tests/run-all.js`**: short profile is now 29 tests (adds `paleo`).

## 4. The honest result: stable, scored, but **not convergent**

The forward runs do **not** converge to the modern map. IoU plateaus around **0.25–0.32**
(neither trajectory approaches 1; Pangaea's best moment is mid-run at 150 Ma, then decays).
This is a genuine physics gap, not a checkpoint or harness bug: the procedural mantle drifts
the continents plausibly but is **unsteered** — nothing drives it along the real Phanerozoic
kinematics (the packs carry no poles and the real rotation history is not yet ingested), so it
cannot reproduce the actual breakup geometry.

Consequently 0.4.5 claims exactly what the measurements support:

- the default Earth start is real Earth (modern plates, continents, sea level);
- two historical starts boot, are loader- and UI-verified, and run a full epoch stably;
- a working, deterministic IoU scoring harness with measured trajectories.

And it explicitly does **not** claim: that the simulation reconstructs the modern map from a
checkpoint, or that older checkpoints are ready. Both are the follow-up milestone
(**reconstruction fidelity** — ingest the Scotese PaleoAtlas v3 `.rot` poles and steer the
forward run), which gates the staged addition of 150 → 20 Ma per
`0.4.0-Earth-map-plan.md` §8.1.

## 5. Next, in order

1. **Reconstruction fidelity milestone**: ingest the `.rot` poles for 250/200 Ma, expose a
   prescribed-rotation-history path (the `prescribedOmega` machinery exists for the modern
   poles), and define a passing IoU target (e.g. final-run IoU ≥ 0.6, or best-in-epoch ≥ 0.7 —
   to be fixed once the pole-driven run is measured).
2. Bake **150 Ma** (first gated checkpoint), re-run the forward gate from it.
3. Continue down the table (100, 66, 40, 20 Ma) as each gate passes.
