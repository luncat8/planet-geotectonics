Planet Geotectonics — GPU (WebGPU) benchmark

Two time-boxed measurements per config, on your GPU. iso = the kernel graph only: submit steps frames and await onSubmittedWorkDone — no event round trips, no drawing. smooth = the full play path (GpuSim.advance, including the event and checkpoint round trips) under requestAnimationFrame, reporting the frame-gap distribution. Rows whose smooth median clears ~16.7 ms sustain 60 fps and are highlighted. The top-kernel GPU ms table (timestamp queries) prints under the table when the adapter supports it. Open this file in a real browser — a sandbox with no WebGPU adapter skips.

iso ms/step is the GPU kernel graph for steps consecutive frames divided by steps (one onSubmittedWorkDone per sample); the 1-vs-5 gap exposes the per-step fixed cost. smooth med/p95/max are rAF frame gaps in ms; a hitch is a gap over 2× the median. Myr/s = simulated time per wall second on the smooth path. Sampling is time-boxed (~1.2 s per iso config, ~5 s per smooth config, capped sample counts) so a heavy level returns in bounded time. ?fast=1 shrinks the boxes for a quick pass on slow renderers; ?noauto=1 suppresses the auto-run; ?level=6&steps=8&dt=0.1 pre-fills the inputs (used by experiments/gpu-bench.js via PGT_QUERY).
