Consequence: Phase I baseline numbers are owner-rig numbers.
  - In-page: open index.html?bench=1 in a real-GPU browser (Chrome). The perf
    strip shows per-kernel GPU ms (ts=on) while playing; the bench suite prints
    iso1/iso5/iso20 ms/step + smooth med/p95/max/hitches.
  - Headless: node experiments/gpu-bench.js --out=experiments/logs/... on a
    machine where the rig has an adapter (PGT_CHROME / PGT_PUPPETEER /
    PGT_LIBS), then replace this file with the real baseline. The driver
    loads bench.html (the standalone bench GUI; index.html?bench=1
    redirects there).
  - Bench inputs: Levels / Steps / dt on the page, or
    PGT_QUERY='level=6&steps=8&dt=0.1' for the driver (?level=&steps=&dt=
    pre-fill the page). Default matrix L5,L6 x 1,5,20 steps, dt 0.1:
    one row per config with iso ms/step + smooth med/p95/max/hitches/Myr/s,
    plus a BENCH kernels: line (top-10 from the timestamp ring) when the
    adapter has timestamp-query.
