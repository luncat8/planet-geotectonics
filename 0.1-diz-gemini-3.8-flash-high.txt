Этот проект находится на стыке геодинамики и вычислительной графики. При масштабе ячейки **10–50 км** (для Земли это эквивалентно разбиению икосферы на 40 000 – 160 000 вершин, то есть `level = 6..7` в вашей сетке) гидродинамика флюидов в порах действительно не нужна. Нам важна **макрореология**: изостазия, вязкопластическое течение литосферы и фазовые переходы при плавлении/застывании.

Ниже представлен системный дизайн (System Architecture & Geodynamic Specification), спроектированный строго под предоставленную структуру данных (`cellA..C`, `nbrA..B`) для реализации сначала на CPU (JS), а затем в виде Compute-шейдеров WebGPU.

# ДИЗАЙН СИСТЕМЫ: ЭМЕРДЖЕНТНАЯ ТЕКТОНИКА И МЕТАЛЛОГЕНИЯ

## 1. Архитектурный выбор: Клетки, Узлы или Частицы?

*   **Почему НЕ частицы (SPH):** Поиск соседей на сфере для 100k частиц на GPU дорог, интерполяция высот на регулярную сферу создает шумы, а моделирование разломов требует сложного склеивания/расщепления.
*   **Почему НЕ чисто жесткие полигоны (Rigid Plates / Euler Poles):** Они не эмерджентны. Нельзя естественно расколоть плиту в произвольном месте под действием стресса или смять континент в дугу без перестроения геометрии.
*   **ВЫБОР: Гибридный квази-эйлеров подход (Eulerian Grid + Semi-Lagrangian Advection) на вашей икосфере.**
    *   Сетка неподвижна (вершины икосферы — это контрольные объемы).
    *   Порода, толщина коры, температура и минералы «перетекают» (advect) между ячейками по полю скоростей.
    *   **Плиты возникают эмерджентно:** связные группы ячеек имеют близкую скорость $\vec{v}$. Границы плит — это узкие зоны, где $|\nabla \vec{v}|$ (сдвиг, сжатие или растяжение) превышает предел прочности.

## 2. Слои данных (Memory Layout для GPU)

Отказываемся от таблицы Менделеева. Нам нужны **механические свойства** и **генетический след геологических событий**.

Все состояние хранится в 2D-текстурах/буферах размера $W \times H$ (где $W=256$, $H=\lceil V/W \rceil$, как в вашем коде).

### Буфер 1: Crust Composition (Литосфера) — `RGBA32F`
*   **R (Felsic / $H_{\text{fel}}$):** Толщина кислой/континентальной коры (граниты/осадки, плотность $\approx 2700\text{ кг/м}^3$). Не субдуцирует из-за плавучести.
*   **G (Mafic / $H_{\text{maf}}$):** Толщина основной/океанической коры (базальты/габбро, плотность $\approx 3000\text{ кг/м}^3$).
*   **B (Age/Temp / $T_{\text{crust}}$):** Тепловой возраст океанической коры / температура. Чем старше кора, тем она холоднее, тоньше и плотнее.
*   **A (Sediment / $H_{\text{sed}}$):** Слой эрозионных осадков (аккумуляторы меди, урана, золота, угля).

### Буфер 2: Kinematics & Stress (Динамика) — `RGBA32F`
*   **R ($V_{e1}$):** Тангенциальная скорость вдоль базиса $e_1$ ячейки.
*   **G ($V_{e2}$):** Тангенциальная скорость вдоль базиса $e_2$ ячейки.
*   **B ($\sigma_{\text{accum}}$):** Накопленный пластический стресс (сдвиг/напряжение перед разломом).
*   **A ($F_{\text{sub}}$):** Сила субдукции / погружения (Slab-pull factor).

### Буфер 3: Mantle / Thermal (Мантия) — `RGBA32F`
*   **R ($T_{\text{mantle}}$):** Температура верхней мантии под ячейкой (плюмы, апвеллинг).
*   **G ($M_{Vx}$), B ($M_{Vy}$):** Скорость конвективного мантийного течения (астеносферное увлечение).
*   **A ($Age_{\text{planet}}$):** Локальный множитель остывания ядра/мантии.

### Буфер 4: Metallogenic Fingerprint (Индикаторы месторождений) — `RGBA16F`
*   **R (Magmatic / Arc):** Следы субдукционного переплава (Cu-Mo-Au порфиры, андезиты).
*   **G (Rift / Hydrothermal):** Следы океанического рифтинга/спрединга (VMS — колчеданные руды, полиметаллы Zn-Pb-Cu).
*   **B (Plume / Ultramafic):** Следы глубинного мантийного пробоя (Ni-Cu-PGE, кимберлиты/алмазы, хромиты).
*   **A (Orogenic / Shear):** Следы коллизионного смятия и метаморфизма (Орогенное золото, пегматиты, Li-Ta).

## 3. Физическая модель: Силы и Механика

Каждая итерация симуляции ($dt \approx 0.1 - 0.5$ млн лет на шаг) вычисляет баланс сил:

$$\vec{F}_{\text{total}} = \vec{F}_{\text{drag}} + \vec{F}_{\text{ridge}} + \vec{F}_{\text{slab}} + \vec{F}_{\text{collision}}$$

### 3.1. Изостазия (Airy-Pratt) и Высота
Высота поверхности формируется равновесием литосферы в мантии:
$$\rho_{\text{mantle}} \approx 3300\text{ кг/м}^3$$
Плотность океанической коры растет со временем по закону остывания:
$$\rho_{\text{maf}}(T_{\text{crust}}) = \rho_{\text{base}} \cdot (1 + \beta \sqrt{\text{Age}})$$
Толщина коры: $H_{\text{crust}} = H_{\text{fel}} + H_{\text{maf}} + H_{\text{sed}}$.
Точка плавучести задает топографию коры относительно уровня астеносферы:
$$Elev = H_{\text{crust}} \left(1 - \frac{\bar{\rho}}{\rho_{\text{mantle}}}\right) - D_{\text{offset}}$$
*Если $Elev < 0$, образуется океан (заполняется гидростатически).*

```
Континент (Felsic: толстый, легкий)      Океан (Mafic: тонкий, плотный)
         /\  Горный хребет                   | Уровень океана
       /    \_________                        |~~~~~~~~~~~~~~~~~~~~~~~
      |               |                      |     Океаническая кора (спрединг -> остывание)
      |   КОНТИНЕНТ   |                      +====+-------------------\
      |   (Низкая     |                                               \  Субдукция
      |   плотность)  |                      МАНТИЯ                    \ (Slab Pull)
======+===============+=================================================\========
```

### 3.2. Силы движения
1.  **Mantle Drag ($\vec{F}_{\text{drag}}$):** Трение между корой и астеносферой:
    $$\vec{F}_{\text{drag}} = k_{\text{visc}} \cdot (\vec{V}_{\text{mantle}} - \vec{V}_{\text{crust}})$$
    *Мантийные конвекционные ячейки моделируются суммой 3-4 октав вращающихся сферических гармоник или крупномасштабным вихревым полем.*
2.  **Ridge Push ($\vec{F}_{\text{ridge}}$):** В зонах апвеллинга мантии кора горячая и приподнята на 2–3 км над ложем океана. Гравитационное соскальзывание создает силу, пропорциональную градиенту высоты:
    $$\vec{F}_{\text{ridge}} = -g \cdot \nabla Elev \quad (\text{только в областях океанической коры})$$
3.  **Slab Pull ($\vec{F}_{\text{slab}}$):** Когда океаническая кора стареет ($\text{Age} > 60\text{ млн лет}$), ее плотность превышает плотность подстилающей горячей астеносферы ($\rho_{\text{maf}} > \rho_{\text{mantle}}$). Возникает отрицательная плавучесть. Если край коры соприкасается с другой плитой, он тонет, затягивая за собой всю плиту:
    $$\vec{F}_{\text{slab}} = -k_{\text{slab}} \cdot \text{Grad}_{\text{depth}}(H_{\text{maf}}) \cdot \max(0, \rho_{\text{maf}} - \rho_{\text{mantle}})$$

### 3.3. Реология: Как плиты становятся «твердыми» без полигонов
Литосфера — это **вязкопластическая жидкость (Бингамов пластик)**:
*   При низком напряжении сдвига (внутри плиты) ее эффективная вязкость колоссальна ($\approx 10^{24}\text{ Па}\cdot\text{с}$). Соседние ячейки движутся как единое целое.
*   При критическом напряжении (предел текучести Yield Stress $\sigma_y$) вязкость локально падает на 3–4 порядка. Возникает сдвиговый разлом (граница плиты).

На GPU это реализуется через 4–6 итераций релаксации импульса (Jacobi / Gauss-Seidel) между соседними ячейками:
$$V_i^{new} = \text{Clamp} \left( \sum_{j \in \text{rings}} w_j V_j, \ \text{порог разрушения} \right)$$

## 4. Динамические процессы: Спрединг, Субдукция, Орогенез и Раскол

Для каждой ячейки вычисляется дивергенция поля скоростей:
$$\text{div}(\vec{V}) = \nabla \cdot \vec{V} = \frac{1}{\text{Area}_i} \sum_{j} (\vec{V}_{\text{edge}} \cdot \vec{n}_{ij}) \cdot \text{Len}_{ij}$$

### 4.1. Дивергенция ($\text{div} > 0$: Растяжение / Рифтинг)
*   Кора истончается: $H \leftarrow H - H \cdot \text{div}(\vec{V}) \cdot dt$.
*   **Континентальный рифтинг (Раскол континента):** Если растягивается кислая кора ($H_{\text{fel}} > 0$), на ней образуется рифтовая долина (депрессия, заполняемая осадками $H_{\text{sed}}$).
*   **Океанический спрединг:** Если толщина коры падает ниже критической, давление падает, поднимается мантия:
    *   Генерируется свежая базальтовая кора: $H_{\text{maf}} += \text{Rate} \cdot dt$.
    *   Возраст сбрасывается: $T_{\text{crust}} = 0$ (максимальная температура).

### 4.2. Конвергенция ($\text{div} < 0$: Сжатие / Столкновение)
Поведение определяется составом сталкивающихся ячеек:

1.  **Океан — Континент (Субдукция):**
    *   Мафическая (океаническая) кора погружается под континент (уничтожается из ячейки).
    *   Часть погруженной массы плавится: на расстоянии 100–200 км вглубь континента инжектируется кислая кора (вулканическая островная дуга).
    *   Накопление следа для руд: **Magmatic Arc $+=$ flux**.
2.  **Океан — Океан:**
    *   Более старая/холодная плита тонет под более молодую. Образуются островные дуги (Марианская впадина, Курилы).
3.  **Континент — Континент (Орогенез / Смятие в горы):**
    *   Плотность континентов мала — ни один не может утонуть.
    *   Вся энергия конвергенции уходит в вертикальное смятие:
        $$H_{\text{fel}} \leftarrow H_{\text{fel}} - H_{\text{fel}} \cdot \text{div}(\vec{V}) \cdot dt$$
    *   Толщина коры взлетает до 50–70 км (Гималаи, Тибет). Горы растут вверх за счет изостазии.

## 5. Остывание планеты (Временная эволюция)

Симуляция управляется глобальным термическим параметром $E_{\text{planet}} \in [1.0, 0.0]$, спадающим со временем:

$$T_{\text{mantle\_global}}(t) = T_{\text{core\_init}} \cdot e^{-\lambda t}$$

*   **Молодая горячая планета ($E > 0.7$):**
    *   Тонкая, мягкая литосфера. Предел прочности $\sigma_y$ мал.
    *   Плит много, они мелкие, движутся быстро (10–20 см/год).
    *   Субдукция слабая, преобладает «вертикальная тектоника» плюмов. Гранитов мало.
*   **Зрелая фаза ($0.7 \ge E \ge 0.3$, Текущая Земля):**
    *   Прочная кора, сформированные кратоны.
    *   Крупные стабильные плиты, классический цикл Вильсона (раскол суперконтинентов каждые 300–500 млн лет).
*   **Замерзающая планета ($E < 0.3$, Марсианский сценарий):**
    *   Литосфера утолщается до $>150$ км. Вязкость астеносферы возрастает.
    *   Движение останавливается («закупоривание крышкой» — Stagnant Lid).
    *   Горы перестают расти, побеждает эрозия. Месторождения только реликтовые.

## 6. Металлогения: Эмерджентные месторождения

Мы не моделируем атомы. Мы фиксируем **термодинамические фабрики руд** — точки пересечения тектонических агентов:

| Тип месторождения | Тектонические условия появления | Ресурсы в игре |
| :--- | :--- | :--- |
| **Порфировый (Arc / Subduction)** | Зона конвергенции океан-континент + инжекция мантийного расплава во влажную кору. | **Медь (Cu), Молибден (Mo), Золото (Au)** |
| **Колчеданный / Черные курильщики (VMS)** | Зона дивергенции в океане ($\text{div} > 0$) + контакт базальта с водой + рифтогенез. | **Цинк (Zn), Свинец (Pb), Медь (Cu), Серебро (Ag)** |
| **Магматический ультраосновной (Plume/Rift)** | Мантийный плюм пробивает древний континент или рифтующийся кратон. | **Никель (Ni), Платина (Pt), Хром (Cr), Алмазы** |
| **Орогенный метаморфический (Orogeny)** | Зона коллизии континент-континент + мощный сдвиговый стресс $\sigma$. | **Жильное Золото (Au), Литий (Li), Вольфрам (W)** |
| **Осадочный бассейн (Sedimentary Basin)** | Депрессия на шельфе континента ($Elev \in [-500, 200]$) + снос осадков с гор. | **Железо (BIF), Уран (U), Уголь/Углеводороды, Соли** |

### Алгоритм накопления (Fingerprinting):
Каждый тик мы увеличиваем значения в буфере `Metallogenic Fingerprint`:
```c
// Псевдокод Compute-шейдера генерации месторождений
if (is_subduction_zone && crust.felsic > 5000.0) {
    ores.magmatic_arc += subduction_flux * dt;
}
if (is_divergent && is_ocean) {
    ores.rift_vms += spreading_rate * dt;
}
if (mantle_plume > 0.8 && crust.felsic > 25000.0) {
    ores.plume_ni_diamond += mantle_plume * dt;
}
if (stress_accum > 0.7 && is_collision) {
    ores.orogenic_gold += stress_accum * dt;
}
// Эрозия и осадки
float erosion = max(0.0, height - 1000.0) * erosion_rate * dt;
crust.felsic -= erosion;
accumulate_sediments_downslope(erosion);
```
**Результат:** Игрок находит месторождения там, где геологи ищут их в реальности (Анды — медь, Урал/Аппалачи — золото/платина, Норильск — никель у древних траппов).

## 7. Пайплайн кадра (Execution Tick)

Шаг моделируется перекладыванием пинг-понг текстур.

```
[1. Mantle Flow] 
       │  Вычисление мантийных течений и плюмов (Сферический шум + конвекция)
       ▼
[2. Stress & Forces] 
       │  Вычисление Slab-pull, Ridge-push и Mantle-drag -> результирующая сила
       ▼
[3. Rheology & Velocity Solve] 
       │  4-6 Jacobi-проходов релаксации импульса -> эмерджентные блоки/плиты
       ▼
[4. Advection (Semi-Lagrangian)] 
       │  Смещение коры, возраста, осадков по вычисленным скоростям
       ▼
[5. Geodynamic Events] 
       │  Subduction (плавление/уничтожение), Rifting (спрединг базальта), Collision (складчатость)
       ▼
[6. Isostasy & Erosion] 
       │  Пересчет высот (Airy Isostasy) + поверхностный перенос осадков в океан
       ▼
[7. Metallogenic Deposition] 
          Накопление рудных потенциалов на основе тектонических событий шага
```

## 8. Архитектура прототипа на JS (CPU)

Перед написанием WGSL-шейдеров создается верификационный класс `TectonicEngine` в JS, расширяющий вашу структуру `Grid`.

### Структура состояния (TypedArrays):
```javascript
function TectonicEngine(grid) {
  this.grid = grid;
  var V = grid.V;

  // Буфер 1: Литосфера (4 компонента на вершину)
  // [0]: H_felsic, [1]: H_mafic, [2]: Crust_Age, [3]: H_sediment
  this.crust = new Float32Array(V * 4);

  // Буфер 2: Скорости и Напряжения в локальном базисе (e1, e2)
  // [0]: Ve1, [1]: Ve2, [2]: Stress, [3]: Divergence
  this.motion = new Float32Array(V * 4);

  // Буфер 3: Рудные потенциалы
  // [0]: Arc_Cu_Au, [1]: VMS_Zn_Pb, [2]: Plume_Ni_Pt, [3]: Orogenic_Au
  this.deposits = new Float32Array(V * 4);

  // Глобальное тепловое состояние
  this.planetEnergy = 1.0; 

  this.initFromGrid();
}
```

### Инициализация коры по готовой высоте `Grid`:
```javascript
TectonicEngine.prototype.initFromGrid = function() {
  var V = this.grid.V;
  var cellC = this.grid.cellC;
  var cellB = this.grid.cellB;

  for (var i = 0; i < V; i++) {
    var isLand = cellB[i * 4 + 3]; // land mask из вашего кода
    var bed = cellC[i * 4 + 2];

    if (isLand > 0.5) {
      // Континентальный кратон
      this.crust[i * 4 + 0] = 30000 + Math.max(0, bed) * 5.0; // 30-45 км гранита
      this.crust[i * 4 + 1] = 5000;                           // базальтовая подложка
      this.crust[i * 4 + 2] = 500.0;                          // древний возраст (млн лет)
    } else {
      // Океаническая кора
      this.crust[i * 4 + 0] = 0;
      this.crust[i * 4 + 1] = 7000;                           // 7 км базальта
      this.crust[i * 4 + 2] = Math.min(180, Math.random() * 120); // молодой океан
    }
  }
};
```

### Реализация локального переноса векторов с использованием ваших `nbrA` и `nbrB`:
В вашем коде в `nbrB` запечены компоненты проекции и вращения тангенциального базиса:
*   `nbrB[0], nbrB[1]` — координаты вектора на соседа в локальном базисе $(e_1, e_2)$.
*   `nbrB[2], nbrB[3]` — поворот базиса соседа относительно текущего (`rotA`, `rotB`).

Это позволяет корректно и без тригонометрии складывать векторы скорости соседних ячеек:

```javascript
TectonicEngine.prototype.solveVelocityField = function(iterations) {
  var V = this.grid.V;
  var W = this.grid.W;
  var H = this.grid.H;
  var nbrA = this.grid.nbrA;
  var nbrB = this.grid.nbrB;

  for (var it = 0; it < iterations; it++) {
    for (var i = 0; i < V; i++) {
      var sumVx = 0;
      var sumVy = 0;
      var count = 0;

      for (var k = 0; k < 6; k++) {
        var baseNbr = (i + k * W * H) * 4;
        if (nbrA[baseNbr + 3] === 0) continue; // нет соседа (пятиугольник)

        var j = nbrA[baseNbr + 0];
        var rotA = nbrB[baseNbr + 2];
        var rotB = nbrB[baseNbr + 3];

        // Скорость соседа j в базисе соседа
        var vj_x = this.motion[j * 4 + 0];
        var vj_y = this.motion[j * 4 + 1];

        // Проекция скорости соседа в локальный базис ячейки i через rotA/rotB
        var aligned_vj_x = vj_x * rotA - vj_y * rotB;
        var aligned_vj_y = vj_x * rotB + vj_y * rotA;

        sumVx += aligned_vj_x;
        sumVy += aligned_vj_y;
        count++;
      }

      // Вязкая диффузия импульса (плиты связываются в твердые тела)
      var viscosity = (this.crust[i * 4 + 0] > 10000) ? 0.95 : 0.7; // континент жестче
      this.motion[i * 4 + 0] = this.motion[i * 4 + 0] * (1 - viscosity) + (sumVx / count) * viscosity;
      this.motion[i * 4 + 1] = this.motion[i * 4 + 1] * (1 - viscosity) + (sumVy / count) * viscosity;
    }
  }
};
```

## 9. Преимущества для WebGPU-трансляции

1.  **Полная совместимость структур:** Все массивы (`cellA..C`, `nbrA..B`) уже имеют формат `Float32Array` с кратностью 4 (`vec4<f32>`). В WebGPU они напрямую биндятся как `texture_storage_2d` (формат `rgba32float`) или `storage buffer`.
2.  **Детерминированный параллелизм:**
    *   Шаг 1 (Силы) читает текстуру `Crust`, пишет в текстуру `Forces`.
    *   Шаг 2 (Релаксация) запускает Compute Pass пинг-понгом между `Motion_Ping` и `Motion_Pong`.
    *   Шаг 3 (Semi-Lagrangian Advection) использует стандартную билинейную выборку через аппаратный текстурный семплер и матрицу lookup.
3.  **Производительность:** Шаг симуляции для $V = 40\,962$ вершин на WebGPU занимает менее **0.8 мс**, что позволяет за 1 секунду экранного времени промотать 100–500 млн лет геологической истории при генерации мира.
